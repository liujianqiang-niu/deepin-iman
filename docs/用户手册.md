# deepin-iman 用户手册

## 1. 简介

deepin-iman 是一款 AI 驱动的 man 手册查看器，专为 deepin/UOS 系统设计。它将传统的 man 手册浏览体验与 AI 能力深度融合，帮助用户更高效地学习和使用 Linux 命令。

应用采用单实例模式运行，重复启动时会自动激活已有窗口，避免多开导致数据库冲突。

## 2. 界面布局

应用主窗口分为以下区域：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  标题栏：[← 后退] [→ 前进]  deepin man 手册  [菜单] [_] [□] [×]                │
├──────────┬────────────────────────┬────────────────────┬────────────────────┤
│          │                        │                    │                    │
│ 左侧栏   │  原文面板               │  翻译/样例面板      │  AI 助手面板        │
│          │  [原文  ×]             │  [翻译/样例  ×]    │                    │
│ [搜索框] │  man 手册阅读区         │  (按需显示)         │  当前模型标签       │
│ [Aa][ab] │  (HTML 渲染)           │  可单独关闭         │  模型下拉框         │
│          │                        │                    │  翻译语言选择       │
│ 手册列表 │                        │                    │  对话显示区         │
│          │                        │                    │  输入框             │
│          │                        │                    │ [翻译][样例][提问]  │
│          │                        │                    │                    │
└──────────┴────────────────────────┴────────────────────┴────────────────────┘
```

- **左侧栏**：搜索框（带大小写/全字匹配开关）+ man 手册列表
- **原文面板**：以 HTML 格式渲染 man 手册内容，支持交叉引用链接跳转，标题栏右侧 × 可关闭，⊘ 可弹出为独立窗口
- **翻译/样例面板**：点击翻译或生成样例时出现，与原文面板并排，标题栏右侧 ⊘/× 可弹出为独立窗口或单独关闭
- **AI 面板**：AI 助手对话区，提供翻译、样例生成、问答等功能

> **弹出独立窗口**：分栏宽度有限时长行不好看，可点击面板标题栏的 ⊘ 弹出按钮或双击标题栏，将面板弹出为独立窗口（可拖动移动、自由调整大小）。关闭独立窗口后面板自动回嵌到主分栏原位置。原文面板和翻译/样例面板都支持。

## 3. 核心功能

### 3.1 man 手册浏览

1. 启动应用后，左侧栏会自动扫描并索引系统中所有 man 手册
2. 首次启动时会出现索引进度对话框，请耐心等待
3. 后续启动时自动检测新增/删除的 man 手册并增量更新索引
4. 手册按名称排列在左侧栏列表中，点击即可打开

### 3.2 搜索

左侧栏搜索框支持三种匹配模式，通过旁边的按钮切换：

- **默认模式**：不区分大小写，包含匹配（输入 `ls` 可匹配 `ls`、`false`、`ols` 等）
- **区分大小写**（点击 **Aa** 按钮）：严格按输入大小写匹配
- **全字匹配**（点击 **ab** 按钮）：只匹配完整的命令名，如输入 `ls` 只匹配 `ls`，不匹配 `false`

两个开关可组合使用。输入 1 个字符即触发搜索，200ms 防抖避免过多查询。

### 3.3 交叉引用导航

1. man 手册中的 SEE ALSO 部分包含交叉引用链接（如 `ls(1)`）
2. 点击链接可直接跳转到相关手册
3. 使用标题栏的 **后退**（←）和 **前进**（→）按钮或快捷键浏览历史
4. 快捷键：`Alt+Left` 后退，`Alt+Right` 前进

### 3.4 AI 翻译

1. 打开任意 man 手册后，AI 面板自动加载当前手册信息
2. 在 AI 面板选择翻译目标语言（中文、English、日本語、Français、Deutsch、Español、Русский，默认中文）
3. 点击 **翻译** 按钮
4. 翻译优先级：**本地缓存 > AI 翻译 > 预设中文包降级**
   - 缓存按目标语言隔离：同一手册翻译成不同语言会分别缓存，互不干扰
   - 若该手册已翻译过（相同语言），直接从本地缓存读取，不重复调用 AI
   - 否则调用 AI 翻译（完整手册正文，不截断），结果缓存到本地供下次复用
   - 若 AI 未配置或请求失败，自动降级使用系统预设中文 man 包（`manpages-zh`，HTML 格式）
5. 若无法提取手册正文（如 mandoc 未安装或手册文件损坏），会提示错误，不会发送空内容给 AI
6. 翻译结果在原文面板右侧的独立面板中显示，两个面板都可单独关闭

### 3.5 AI 使用样例生成

1. 打开任意 man 手册后，点击 **生成样例** 按钮
2. AI 会根据手册所属 section 自动判断类型并生成相应样例：
   - **用户命令/管理命令**（section 1/8）：生成命令行样例，包含命令、注释说明、预期输出
   - **系统调用/库函数**（section 2/3，如 `printf(3)`、`open(2)`）：生成 C 语言代码样例，包含头文件、main 函数、编译运行说明
3. AI 基于手册真实正文内容生成样例（完整正文，不截断），不臆造
4. 样例结果缓存到本地，再次生成同一手册的样例时直接从缓存读取，不重复调用 AI
5. 样例结果在原文面板右侧的独立面板中显示，可单独关闭

### 3.6 AI 问答

1. 打开任意 man 手册后，在 AI 面板底部输入框中输入问题
2. 点击 **提问** 按钮
3. AI 会基于当前手册内容回答你的问题
4. 适用于理解复杂参数、查找特定用法等场景

### 3.7 命令解析（已移除）

该功能已在新版本中移除。

### 3.8 收藏

1. 打开手册后，点击标题栏菜单中的 **收藏当前页**
2. 再次点击可取消收藏
3. 点击菜单中的 **收藏列表** 可查看所有收藏
4. 在弹出的列表中双击条目可直接跳转到对应手册
5. 选中列表条目后点击 **删除选中收藏** 按钮可删除单个收藏

### 3.9 浏览历史

1. 系统自动记录你浏览过的手册
2. 点击菜单中的 **浏览历史** 可查看最近浏览记录
3. 在弹出的列表中双击条目可直接跳转
4. 历史记录最多保留 100 条，超出自动清理旧的记录

### 3.10 刷新索引

1. 点击菜单中的 **刷新索引** 可手动重新扫描 man 手册
2. 扫描过程中显示进度对话框
3. 完成后在 AI 面板显示索引总数
4. 安装/卸载 man 手册包后建议刷新索引

### 3.11 数据管理

1. 点击菜单中的 **数据管理** 打开数据清理对话框
2. 勾选要清理的项目（支持多选）：
   - **清空翻译缓存**：删除所有已翻译内容的本地缓存，下次翻译会重新调用 AI
   - **清空浏览历史**：删除所有浏览历史记录
   - **清空收藏列表**：删除所有收藏
   - **清空索引数据库**：删除 man 手册索引，下次启动自动重新扫描重建
3. 点击 **确认清理** 立即执行清理（操作不可恢复，请谨慎）
4. 清理过程中会显示进度条，完成后在 AI 面板显示结果
5. 若清空了索引数据库，下次启动应用时会自动重新扫描重建，无需手动干预

### 3.12 弹出独立窗口

左右分栏时每栏宽度有限，长行内容不便阅读，可将面板弹出为独立窗口：

1. **触发方式**（两种皆可）：
   - 点击面板标题栏右侧的 ⊘ 弹出按钮
   - 双击面板标题栏
2. 面板会从主窗口分栏中取出，变为一个独立窗口
3. 独立窗口可自由拖动移动位置、调整窗口大小，内容完整显示不受分栏宽度限制
4. 关闭独立窗口，面板自动回嵌到主窗口分栏的原位置

原文面板和翻译/样例面板都支持弹出为独立窗口。

## 4. AI 模型设置

### 4.1 打开设置

点击标题栏右上角菜单 → **AI 设置**，打开 AI 模型厂商管理界面。

### 4.2 内置模型厂商

deepin-iman 预置以下 OpenAI 兼容的模型厂商：

| 厂商 | Base URL | 默认模型 |
|------|---------|---------|
| OpenAI | `https://api.openai.com/v1` | gpt-4o |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | glm-4-plus |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-max |
| DeepSeek | `https://api.deepseek.com/v1` | deepseek-chat |

> **说明**：Base URL 是 API 的基础地址，不需要包含 `/chat/completions` 路径，应用会自动拼接。

### 4.3 配置模型厂商

1. 在厂商列表中选中要配置的厂商
2. 在编辑区域填写以下信息：
   - **厂商名称**：显示名称，可自定义
   - **Base URL**：厂商的 OpenAI 兼容 API 基础地址（如 `https://api.openai.com/v1`）
   - **API Key**：在厂商平台申请的 API 密钥
   - **模型名称**：要使用的模型名称
3. 点击 **测试连接** 验证配置是否正确，状态栏会显示连接结果
4. 点击 **设为当前** 将该厂商设为默认使用的模型
5. 点击 **保存** 按钮保存所有配置

### 4.4 添加自定义厂商

deepin-iman 兼容所有 OpenAI API 格式的厂商。

1. 点击 **添加厂商** 按钮
2. 在编辑区域填写厂商信息：
   - **厂商名称**：如 "OpenRouter" 或 "本地模型"
   - **Base URL**：OpenAI 兼容的 API 基础地址（通常以 `/v1` 结尾）
   - **API Key**：对应厂商的 API 密钥
   - **模型名称**：如 `gpt-4o-mini`、`deepseek-reasoner` 等
3. 点击 **测试连接** 验证配置
4. 点击 **设为当前** 选择该厂商
5. 点击 **保存**

常见 OpenAI 兼容厂商示例：

| 厂商 | Base URL | 模型示例 |
|------|---------|---------|
| OpenRouter | `https://openrouter.ai/api/v1` | `anthropic/claude-3.5-sonnet` |
| Ollama 本地 | `http://localhost:11434/v1` | `llama3.1` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-72B-Instruct` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

### 4.5 测试连接

在配置或编辑厂商信息时，点击 **测试连接** 按钮，应用会向该厂商发送一条测试消息：

- **连接成功**：状态栏显示绿色 ✓ 标记和 AI 回复内容
- **连接失败**：状态栏显示红色 ✗ 标记和错误信息

建议在保存配置前先测试连接，确保 Base URL、API Key 和模型名称正确。

### 4.6 删除模型厂商

1. 在列表中选中要删除的厂商
2. 点击 **删除厂商** 按钮
3. 如果删除的是当前使用的厂商，系统会自动切换到列表中的第一个厂商

### 4.7 主界面切换模型

在 AI 面板顶部的下拉框中，可以随时切换当前使用的模型厂商，无需每次打开设置。切换后，下方的"当前模型"标签会实时更新显示厂商名称和模型名称。

### 4.8 查看当前模型

AI 面板标题下方显示"当前模型：厂商名 / 模型名"，让你随时知道正在使用哪个模型。每条 AI 回复消息末尾也会标注 `[模型名]`，方便追溯。

## 8. 依赖

运行 deepin-iman 需要以下组件：

**必须依赖：**

- **mandoc**：man 手册 HTML 渲染引擎
- **manpages**：标准系统命令 man 手册
- **manpages-dev**：C 库函数和系统调用 man 手册

**推荐依赖：**

- **manpages-posix**：POSIX 标准 man 手册
- **manpages-posix-dev**：POSIX 开发 man 手册
- **manpages-zh** 或 **manpages-cn**：中文 man 手册包

安装命令：

```bash
sudo apt install mandoc manpages manpages-dev manpages-posix manpages-posix-dev manpages-zh
```
